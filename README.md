# FTLF notes

Per-country notes for **For the Love of Flags** (Outlines mode), by StudioZYRN. Served by GitHub Pages at `https://studiozyrn.github.io/ftlf-notes/v1/`; the app fetches them when built with `--dart-define=NOTES_BASE_URL=https://studiozyrn.github.io/ftlf-notes/v1/`.

- `v1/index.json`: written by `tool/notes/build_notes_site.py` in the app repo, never by hand.
- `v1/countries/<CC>.json`: one notes file per country.

The source of truth is `notes-site/` in the app repo (`FTLF`, private). Edit and validate there, then copy here and push. The format contract is `docs/NOTES_REMOTE.md` in the app repo.
